# 🏗️ Prerab OS — Строительный ERP / CRM / PM комплекс

Специализированная система управления строительно-ремонтной компанией в Словакии (**Prerab s.r.o.**).

---

## 🌟 Ключевые возможности

1. **🇷🇺 Полностью на русском языке для управления**:
   - Весь внутренний интерфейс, учет маржи, аналитика, чеки и мастера — на русском.
   - Официальные документы для клиентов (**Faktúry**, **Cenové ponuky**, **Preberacie protokoly**) формируются на чистом словацком языке с соблюдением законов Словакии.

2. **🇸🇰 Словацкая специфика "из коробки"**:
   - **Автопоиск по IČO**: Вводите IČO $\rightarrow$ система сама за секунду находит название, адрес, DIČ, IČ DPH и статус плательщика НДС в словацком реестре.
   - **PAY by square**: Автоматическая генерация валидного словацкого QR-кода для мгновенной оплаты через мобильный банк (SLSP, Tatra banka, VÚB, ČSOB, 365.bank).
   - **DPH & § 69 (Строительный реверс)**: Поддержка ставок DPH 23%, 19%, 5% и освобождения по **§ 69 ods. 12 písm. j zákona o DPH** (Prenesenie daňovej povinnosti).
   - **Výkaz výmer & Rozpočtár**: Сметчик с каталогом строительных работ (демонтаж, стяжка, гипсокартон, плитка, сантехника, электрика, малярка) и расчетом чистой маржи в € и в %.

3. **💰 0 € Затрат на облако и разработку ($0 Cost Stack)**:
   - Приложение работает быстро в любом браузере (на ПК в офисе и смартфоне/планшете на объекте).
   - **1-клик бэкап**: Скачивание полной копии всех данных в файл `.json` в любое время.
   - **Supabase Cloud (Бесплатный тариф)**: Приготовлена схема PostgreSQL с Row Level Security (RLS) для защиты коммерческой тайны и цен от конкурентов.

## 🚀 Быстрый запуск

### Вариант 1 (В 1 клик на Windows):
Дважды нажмите на файл **`start.bat`**. Откроется браузер по адресу `http://localhost:3000`.

### Вариант 2 (Через терминал):
```bash
npm run dev
```

## 📁 Структура модулей системы

- 📊 **Дашборд и Аналитика**: Выручка, фактические затраты, чистая прибыль, средняя маржа %, графики Recharts.
- 📁 **Объекты и Проекты**: Список объектов, светофор себестоимости, статус сделки, управление этапами.
- 👥 **CRM Клиенты**: База клиентов с автопоиском по IČO и Канбан-воронкой продаж.
- 🧮 **Сметчик (Výkaz výmer)**: Конструктор смет по помещениям, двойные расценки (себестоимость мастера vs цена для клиента), расчет маржи, печать Cenová ponuka (PDF).
- 🧾 **Расходы и Чеки**: Фиксация чеков Hornbach/OBI, фото чеков, DPH к вычету, контроль перерасхода.
- 💶 **Счета и DPH (Faktúry)**: Выставление счетов, залоговые фактуры, генератор PAY by square, печать официальных словацких фактур (PDF).
- 📥 **Фактуры на уплату (Došlé faktúry)**: Входящие фактуры от магазинов и поставщиков — автоматически принимаются с почты фирмы, статусы «Уплачено / Не уплачено / Просрочено» с датой оплаты, QR-код для оплаты в банке, проведение в расходы.
- 👷 **Мастера и Бригады**: База рабочих, табель часов и объемов, сдельная/почасовая оплата, калькулятор выплат.
- ⚙️ **Настройки и Бэкап**: Реквизиты фирмы Prerab, экспорт и импорт базы данных.

## 📥 Фактуры на уплату: автоприем с почты

Раздел **«Фактуры на уплату»** собирает все входящие фактуры от магазинов и поставщиков
(Hornbach, OBI, SIKO, Stavmat, Slovnaft, аренда техники, вывоз мусора и т. д.) в одном списке.

### Что умеет раздел

| Возможность | Описание |
|---|---|
| 📧 **Автоприем с почты** | Письма с фактурами сами превращаются в записи: поставщик, номер фактуры, VS, IBAN, сумма, DPH и срок оплаты распознаются автоматически |
| ✅ **Уплачено / Не уплачено** | Одна кнопка отмечает фактуру уплаченной — с фиксацией **даты оплаты**, суммы, способа (банк / карта / наличные) и того, кто платил |
| ⚠️ **Контроль просрочки** | Просроченные фактуры подсвечиваются красным, в меню горит счетчик неоплаченных |
| 💳 **QR-код оплаты** | PAY by square / SEPA QR для мгновенной оплаты фактуры поставщику из мобильного банка |
| 📎 **PDF фактуры** | Вложение письма сохраняется на Google Drive, открывается из таблицы в один клик |
| 📧 **Переход к письму** | Кнопка открывает в Gmail то самое письмо, из которого взята фактура |
| 🏗️ **Привязка к объекту** | Объект выбирается прямо в строке списка; если объект сменить, связанный расход переезжает следом |
| 🧾 **Проведение в расходы** | Уплаченная фактура одной кнопкой попадает в «Расходы и Чеки» и в себестоимость объекта |
| 🔁 **Без дублей** | Одно письмо никогда не заводится дважды (проверка по Gmail Message-ID и номеру фактуры) |

### Подключение почты (5 минут, делается один раз)

1. Выполните SQL из `supabase/schema.sql` в Supabase (добавится таблица `supplier_invoices`).
   Без этого шага система тоже работает — фактуры хранятся в облачном документе.
2. Откройте [script.google.com](https://script.google.com) под почтой фирмы → **Новый проект**.
3. Вставьте содержимое файла `scripts/gmail-invoice-sync.gs` и сохраните.
4. В блоке `CONFIG` укажите адрес приложения, например:
   `API_URL: 'https://prerab-os.vercel.app/api/invoices-email'`.
5. Запустите функцию **`nastavitAutomatiku`** и разрешите доступ к Gmail и Drive.

Дальше скрипт каждые 15 минут проверяет почту, кладет PDF на Google Drive и отправляет фактуру в систему.
Проверить связь можно функцией `skontrolovatSpojenie` или открыв `/api/invoices-email` в браузере.

### Защита эндпоинта (необязательно)

Задайте в Vercel переменную окружения `INVOICE_INBOX_SECRET`, а тот же ключ пропишите
в `CONFIG.SECRET` скрипта Gmail — тогда чужие письма в базу не попадут.

### Ручное добавление

Фактуру, пришедшую не по почте (бумажную или из мессенджера), заводят кнопкой
**«Добавить фактуру»** — там же можно приложить PDF или фото документа.
